RREQUEST

A Postman-style REST client that lives inside Visual Studio Code — with optional Google Drive workspace sync.

Get it on the VS Code Marketplace Source on GitHub

What it does

  • Build and send HTTP requests, WebSocket and gRPC calls, with tabs, history and environments.
  • Organize requests into collections and workspaces; import/export Postman and cURL.
  • Pre-request & test scripts with a focused pm API.
  • Optional cloud sync: sign in with Google to sync a workspace across machines and share it (owner / editor / viewer) — each workspace is stored as a single JSON file in your Google Drive.

Cloud sync & your data

Sync is entirely optional and off until you sign in. When enabled, RREQUEST uses the Google drive.file scope, which grants access only to files the app itself creates — never the rest of your Drive. See the details below.
